# OOP Programming

## Overview
This repository demonstrates Object-Oriented Programming (OOP) principles and practices. The project is designed to showcase how encapsulation, inheritance, polymorphism, and abstraction can be used to create modular, maintainable, and extensible software systems.

## Features
- Examples of OOP concepts:
  - **Classes and Objects**
  - **Inheritance**
  - **Polymorphism**
  - **Encapsulation**
  - **Abstraction**
- Sample projects/exercises illustrating OOP in action
- Well-documented code and comments for learning purposes

## Project Structure
```
oop_programming/
├── src/              # Source code implementing OOP examples
│   ├── main.py       # Main entry point
│   ├── animal.py     # Example class demonstrating inheritance
│   ├── vehicle.py    # Example class for abstraction and encapsulation
│   └── ...           # Other OOP concept files
├── tests/            # Unit tests for OOP examples
├── README.md         # Project documentation
└── LICENSE           # License information
```

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/mateuszoleksy/oop_programming.git
   ```
2. Run the main example:
   ```bash
   python src/main.py
   ```
3. Run tests:
   ```bash
   python -m unittest discover tests
   ```
